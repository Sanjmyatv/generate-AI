# zyro.ai админы гарын авлага: загвар нэмэх ба үнийн мэдээлэл

Энэ гарын авлага нь админ самбар (`/admin`) дээр шинэ загвар (template) нэмэх, үнэ тогтоох, ашгийг тооцоход зориулагдсан. Самбарын товч, талбарын нэр Англи хэлээр байдаг тул тэднийг яг тэр хэвээр нь бичсэн.

---

## 1. Эхлэхээс өмнө

- **Админ самбар руу орох:** сайтад нэвтэрч, профайл хуудасны "Admin panel" товчийг дарна, эсвэл хаяг дээр `/admin` гэж бичнэ. Админ биш хэрэглэгчид 404 харна.
- **Админ эрх олгох:** эрхийг зөвхөн өгөгдлийн сан дээр гараар өгдөг (аюулгүй байдлын үүднээс). Railway → Postgres → Data → Query дээр:

```
UPDATE "User" SET "isAdmin" = true WHERE email = 'таны@имэйл.com';
```

- **Хэрэгтэй тохиргоо (Railway хувьсагч):** `HIGGSFIELD_CREDENTIALS` (Genjutsu, Higgsfield зураг), `SEEDANCE_API_KEY` (Seedance), `GEMINI_API_KEY` (видео шинжилгээ). Байхгүй бол тухайн арга ажиллахгүй.

---

## 2. Шинэ загвар нэмэх: алхам алхмаар

**Загвар гэж юу вэ?** Эх видео (эсвэл зураг) + AI арга + нууц prompt + хэдэн зураг авах + үнэ. Хэрэглэгч зөвхөн нэр, тайлбар, зураг, үнийг харна.

### Алхам 1. Загвар үүсгэх

`/admin` хуудсанд **New template** товчийг дарна.

### Алхам 2. Эх видеог оруулах (хамгийн дээд хэсэг)

"Source video" хэсэгт **Template video** талбараар файлаа сонгоно.

- Формат: **MP4 эсвэл MOV**. Дээд хэмжээ **60 MB**. Хамгийн багадаа **4 секунд**.
- Genjutsu нь 30 секунд хүртэл, Genjutsu Light нь эхний **30 секундийг** л ашиглана.
- Бүжигчин (хүн) бүтэн биеэрээ тод, хурдан хөдөлгөөнгүй байвал үр дүн сайн.
- Видеонд бодит хүн байвал **Genjutsu** (эсвэл Light) сонго. Seedance бодит хүнтэй эх видеог татгалздаг.

### Алхам 3. Gemini-д шинжлүүлэх (зөвлөмж)

Видео орсны дараа **Analyze with Gemini** товчийг дарна (1 минут хүртэл хүлээнэ). Gemini дараахыг санал болгоно:

- **Гарчиг** (Монгол ба Англи), 2-4 үг.
- **Маш богино тайлбар** (Монгол ба Англи), нэг өгүүлбэр.
- **Prompt**, **хэдэн хүн** байгаа, зураг тус бүрийн **заавар** (upload хайрцагны доорх текст).
- **Кредитийн үнэ** (доорх 3-р хэсгийг үз).

Бүгдийг нь засаж болно. Сэтгэл хангалуун бол **Apply to this template** дарна. Формын талбарууд бөглөгдөнө. Одоо л хадгалаагүй байгаа тул шалгаад дараа нь хадгална.

> Gemini хүний тоог буруу тоолж болно. Apply хийхээсээ өмнө видеотойгоо тулгаж үзээрэй.

### Алхам 4. Үндсэн мэдээлэл ("Basics")

| Талбар | Юу бичих |
|---|---|
| Name, Description | Англи нэр ба тайлбар (заавал). |
| Name (Монгол), Description (Монгол) | Монгол нэр, тайлбар. Хоосон бол Монгол хэрэглэгч Англи хувилбарыг харна. |
| Category | Байгаа ангиллаас сонго, эсвэл **…or a new category** дээр шинээр бич. |
| Card shape | Нүүр хуудсан дээрх картын хэлбэр (9:16, 3:4, 1:1 …). Босоо видеонд 9:16. |
| Trending order | Хоосон бол "Эрэлттэй" хэсэгт орохгүй. 0 нь хамгийн эхэнд. |
| Visible on the site | Идэвхтэй бол сайтад харагдана. Хасвал нуугдана. |

Тайлбарыг **маш богино** бич (нэг өгүүлбэр, 70 орчим тэмдэгт). Карт дээр хэт урт текст багтахгүй.

### Алхам 5. Арга ба prompt ("Content")

**Output** дээр Видео эсвэл Зураг сонгоно, дараа нь **Method** (хэрхэн хийгдэх):

| Арга | Хэзээ ашиглах |
|---|---|
| Swap into a source video (Genjutsu) | Эх видеоны хөдөлгөөнийг хадгалаад дүрийг хэрэглэгчийн зургаар солино. Бодит хүнтэй ажиллана. Эх видеоны секунд тутамд төлбөртэй. |
| Swap into a source video, cheaper (Genjutsu Light) | Дээрхтэй төстэй, **хамаагүй хямд**. Эх видеоны эхний 30 секундийг ашиглана (секунд тутамд гаралт + эх видео хоёрыг хоёуланг нь төлнө, тиймээс 30 секундийн видео 15 секундийнхээс 2 дахин үнэтэй). Чанарыг эхлээд туршиж үз. |
| Edit a source video (Seedance) | Эх видеог зургаар засна. **Бодит хүнтэй видеог татгалзана.** |
| Create a new video from the photo (Seedance) | Эх видеогүй. Зураг ба prompt-оос шинэ видео үүснэ. |
| Edit the photo (Higgsfield image) | Зургийг засна (сэргээх, өнгөлөх). |

- **Prompt**: хэрэглэгч хэзээ ч харахгүй. Genjutsu-д заавал бичих шаардлагагүй, бусад аргад заавал. Зургуудыг "first reference image", "Image 1" гэх мэтээр дарааллаар нь нэрлээд хэнийг хэнээр солихыг бичнэ.
- **Preview**: картан дээр харагдах зураг эсвэл богино видео (30 MB хүртэл).

### Алхам 6. Чанар ("Quality")

- **Видео:** хэрэглэгч өөрөө **480p** (хурдан, хямд, анхдагч) эсвэл **720p HD** сонгоно. Үнийг дараагийн алхмаар тогтооно. 720p-ийн үнийг хоосон орхивол зөвхөн 480p санал болно.
- **Зураг:** quality, aspect ratio-г энд сонгоно (`auto` нь зургийн хэлбэрийг хэвээр хадгална). **Хэрэглэгч 1K (Стандарт), 2K (HD), 4K (Ultra HD) чанарыг өөрөө сонгоно**, чанар бүр өөр кредиттэй (доорх Алхам 7-г үз).

### Алхам 7. Зураг ба үнэ ("Photos and price")

- **Photos the user uploads:** хэрэглэгч хэдэн зураг оруулах (1-5). Нэг хүнд нэг зураг.
- **Photo type:** Clear face (царай) эсвэл Full body (бүтэн бие).
- **Photo labels:** upload хайрцаг бүрийн доорх нэр, 60 тэмдэгтээс бага (жишээ нь "Зүүн талын залуу"). Хоосон бол "Photo N".
- **Credits per generation:** кредитийн үнэ. **Үүнийг систем өөрөө тооцдог** (доорх 3.4-г үз), гараар бичих шаардлагагүй.
  - **Work out the credits automatically** сонголт анхнаасаа идэвхтэй. Идэвхтэй үед **Credits at 480p**, **Credits at 720p HD** талбар зөвхөн унших горимд байна.
  - **Video length (s):** видеоны урт (харуулах зорилготой).
  - **Зураг:** **Credits at 1K**, **Credits at 2K (HD)**, **Credits at 4K (Ultra HD)**. 2K эсвэл 4K-г хоосон орхивол тэр чанарыг санал болгохгүй. **Хоёулаа хоосон бол** зураг нэг үнэтэй, загварт тохируулсан хэмжээгээр (Resolution) хийгдэнэ.
- **Cost and margin:** өртөг ба ашгийг тооцох хэсэг (доорх 3-р хэсэг).

### Алхам 8. Хадгалах, шалгах

Хамгийн доор **Save** дарна. `/admin` жагсаалтад загвар гарна:

- **Hidden**: сайтад нуугдсан.
- **Not set up: cannot generate yet**: арга сонгоогүй, ажиллахгүй.
- Загвар бүрийн ашгийн хувь (хамгийн хямд багц дээрх тооцоо) харагдана. Улаан бол алдагдалтай.

**Заавал туршиж үз:** загвар идэвхтэй байх үед өөрийн бүртгэлээр нэг удаа **480p** үүсгэж үр дүнг нь шалга. Туршилт бүр жинхэнэ мөнгө (Higgsfield, Seedance, Gemini) зарцуулдаг. Үр дүн муу бол **Hide** дарж нууна. Хэрэглэгчдэд нийтлэхээсээ өмнө ингэж баталгаажуул.

### Алхам 9. Засах, нуух, устгах

| Үйлдэл | Тайлбар |
|---|---|
| **Edit** | Бүх талбарыг засна. Видеог солих бол шинийг оруулна. |
| **Hide / Show** | Устгалгүйгээр нууж, дахин гаргана. |
| **Delete** | Устгана. Хэн нэгэн энэ загвараар үүсгэсэн бол **устгах боломжгүй**, оронд нь Hide хий. |

## 3. Үнийн мэдээлэл

Бүх үнэ **нэг томьёо**, нэг тохиргооноос гарна: үнийн хуудас, төлбөр, загварын засварлагч, админ бүгд адилхан тоо ашиглана.

### 3.1 Үндсэн зарчим

- **1 кредит = ₮100.** Бүх багцад адил (хөнгөлөлтгүй, бонусгүй). Хэтэвч, кредитийн түүхэнд кредит 2 орон хүртэл нарийвчлалтай хадгалагдаж, хэрэглэгчид үргэлж бүхэл тоогоор (дээш бөөрөнхийлсөн) харагдана.
- Кредитийн үнэ **сервер дээр** тооцогдоно. Браузерээс ирсэн үнэд хэзээ ч итгэхгүй.
- Хэрэглэгч үүсгэхэд кредит хасагдаж, амжилтгүй болбол яг тэр хэмжээгээр автоматаар буцна.

### 3.2 Томьёо

```
K       = (1 + retry buffer) / (1 − target margin − gateway fee)     // 1.05 / 0.44 = 2.3864
үнэ (₮) = өртөг (USD) × USD→MNT ханш × K
кредит  = ceil(үнэ / 100)                                            // нэг удаа, нийт дүн дээр
өртөг 480p = секунд × $0.074
өртөг 720p = секунд × $0.074 × 2.015
```

Анхдагч тохиргоотой үеийн үр дүн (бүгд 55% ашигтай):

| Видеоны урт | 480p кредит | 480p үнэ | 720p кредит | 720p үнэ |
|---|---|---|---|---|
| 5 с | 31 | 3,100₮ | 63 | 6,300₮ |
| 10 с | 62 | 6,200₮ | 125 | 12,500₮ |
| 15 с | 93 | 9,300₮ | 187 | 18,700₮ |
| 20 с | 124 | 12,400₮ | 250 | 25,000₮ |

**Зургийн үнэ томьёогоор өөрчлөгдөхгүй:** 1K = 3, 2K = 6, 4K = 10 кредит. Higgsfield-ээс өртгийг нь асууж чадвал "Cost and margin" дээр ашгийг харуулна, гэхдээ үнийг автоматаар солихгүй.

### 3.3 Үнийн тохиргоо (Pricing settings)

`/admin` (Templates) хуудасны дээд талд. Бүх тоо энд засагдана:

| Талбар | Анхдагч |
|---|---|
| Credit value | 100₮ |
| Target margin | 55% |
| Retry buffer | 5% (өртөг дээр нэмэгдэнэ) |
| Payment gateway fee | 1% (орлогоос хасагдана) |
| USD → MNT rate | 3,500 (серверийн `USD_MNT_RATE` анхдагч) |
| Video cost, 480p | $0.074 / секунд (манай дансны бодит өртөг) |
| 720p cost multiplier | 2.015 (нэг бодит 720p үүсгэлтээр баталгаажуул) |
| Reference video length | 15 с (багцын "N видео"-г тоолох урт) |
| Higgsfield list price | $0.10667 / секунд (зөвхөн эрсдэлийн мөрөнд) |
| Price source | Manual (анхдагч) эсвэл Higgsfield lookup |

- **Price source:** Manual бол секунд тутмын тогтмол өртөг. Higgsfield lookup бол загвар бүрээр асууж, **"account price"** (манай дансны) эсвэл **"list price"** (хөнгөлөлтгүй, асуулт амжилтгүй үед) гэж тодорхой тэмдэглэнэ. Нэг дэлгэц дээр хоёр өөр мессеж гарахгүй. Олноор нь дахин тооцоход зөвхөн Manual өртөг ашиглана.
- **Margin at Higgsfield list price:** хөнгөлөлт дуусвал 93 кредитийн видео ашиг хэд болохыг (~36%) харуулна.
- **Тохиргоо өөрчлөхөд** "Automatic credits" тэмдэгтэй загваруудын **хуучин → шинэ** кредитийг жагсааж үзүүлнэ. **Confirm and apply** дарахгүй бол юу ч өөрчлөгдөхгүй. Гараар тавьсан үнэтэй загварт хөндөхгүй.

### 3.4 Загварын засварлагч

- **Work out the credits automatically** идэвхтэй үед 480p/720p кредит томьёогоор гарна (урт нь эх видеоны урт, Genjutsu Light-д дээд тал нь 30 с). Сонголт **загвар дээр хадгалагдана** ("Automatic credits" тэмдэг), тиймээс тохиргоо өөрчлөгдөхөд тэр загварууд шинэчлэгдэнэ.
- Унтраавал талбарууд гараар засагдана (manual override), тэр загвар дахин автоматаар өөрчлөгдөхгүй.
- **Cost and margin** хэсэг: provider cost, charged credits, revenue, нийт өртөг (provider × (1 + retry) + gateway fee), ашиг ₮ ба %. Ашиг зорилгоос (55%) доош бол **улаан анхааруулга** гарна. **Хадгалахыг хориглохгүй.**

### 3.5 Кредитийн багцууд (`/admin/packs`)

| Багц | Төлбөр | Кредит | Зураг (1K) | 15 с видео 480p | 15 с видео 720p |
|---|---|---|---|---|---|
| Туршилтын (Trial) | 5,000₮ | 50 | 16 | 0 | 0 |
| Лайт бүтээгчийн (Light) | 10,000₮ | 100 | 33 | 1 | 0 |
| Про бүтээгчийн (Pro, "Хамгийн их сонгогддог") | 23,000₮ | 230 | 76 | 2 | 1 |
| Бизнесийн (Business) | 45,000₮ | 450 | 150 | 4 | 2 |

- Багцыг **өгөгдлийн санд** хадгална, `/admin/packs` дээр нэр (англи, монгол), үнэ, badge, "queue priority" мөрүүд, харагдах эсэхийг засна. **Кредит = үнэ ÷ credit value**, тиймээс хоорондоо зөрөхгүй.
- Тоонууд (зураг, видео) **тооцоолсон**, доош бөөрөнхийлсөн. Гараар бичихгүй.
- Дүрэм: Trial 15 с видео **0**, Light **≥ 1**, Pro **≥ 2**, Business **≥ 4** видео хамрах ёстой. Зөрчвөл улаан анхааруулга гарна.
- Кредит бүх багцад **нийтлэг**, хугацаа дуусдаггүй. Тиймээс багц тус бүрт хориг байхгүй: **видео загвар нь үнээсээ бага үлдэгдэлтэй хэрэглэгчид түгжигдсэн** ("Энэ видеонд 93 кредит хэрэгтэй" + "Кредит авах"). Зураг (3 кредит) нээлттэй.
- Багц засахад одоо байгаа үлдэгдэл, өмнөх худалдан авалт өөрчлөгдөхгүй.

> **Анхаар:** "Тэргүүлэх боловсруулалтын дараалал", "Дараалын дээд тэргүүлэх эрх" мөр нь үнийн хуудсанд **харагдана**, гэхдээ үүсгэлтийн дараалалд одоогоор **ашиглагддаггүй**.

### 3.6 Шинэ хэрэглэгчийн бэлэг

Google-ээр шинээр бүртгүүлсэн хэрэглэгч **10 кредит** (₮1,000) авна (имэйлээр бүртгүүлэгч авахгүй). Энэ нь 3 зураг хийхэд хүрнэ, видеонд хүрэхгүй.

### 3.7 Олон загварыг дахин тооцох (скрипт)

```
npm run reprice                  # үзүүлэх горим: юу өөрчлөгдөхийг хүснэгтээр хэвлэнэ, юу ч өөрчлөхгүй
npm run reprice -- --apply       # "Automatic credits" загваруудад хэрэгжүүлнэ
npm run reprice -- --apply --include=id1,id2   # хянаж үзсэн гараар тавьсан загваруудыг нэмж хэрэгжүүлнэ
```

Гараар тавьсан загваруудыг тусад нь жагсааж, томьёо юу гэж хэлэхийг харуулна, **хөндөхгүй**.

### 3.8 Ашиг, эрсдэл

- Ашгийн хувь = (орлого × (1 − gateway fee) − provider × (1 + retry)) ÷ орлого.
- USD→MNT ханш өөрчлөгдвөл тохиргоон дээр ханшийг шинэчилж, тохиргооны өөрчлөлтөөр загваруудыг дахин тооцно.
- Манай дансны хөнгөлөлт (өртөг $0.074/с) дуусвал Higgsfield list үнэ ($0.107/с) болж, 15 с видеоны ашиг ~36% болно. "Margin at Higgsfield list price" мөрийг хянаж байгаарай.

## 4. Түгээмэл асуудал

| Асуудал | Шалтгаан ба шийдэл |
|---|---|
| "Not set up: cannot generate yet" | Арга сонгоогүй эсвэл эх видео/prompt дутуу. Загварыг Edit хийж гүйцээгээд Save. |
| Үүсгэлт "Generation failed", кредит буцсан | AI үйлчилгээ татгалзсан. Genjutsu-д эх видео эсвэл зургийг шалга. Railway Deploy Logs дээр `[higgsfield]`, `[gemini]` мөрийг хар. |
| Seedance "template unavailable" | Эх видеонд бодит хүн байна. Genjutsu руу шилжүүл. |
| "Analyze with Gemini" алдаа | `GEMINI_API_KEY` байхгүй, эсвэл эх видео энэ сайтаас оруулсан биш (гаднаас холбосон линк шинжлэгдэхгүй). |
| Хэрэглэгч "Загвар боломжгүй байна" гэж харна | Загварын арга тохируулагдаагүй, эсвэл түүнд хэрэгтэй түлхүүр (`HIGGSFIELD_CREDENTIALS`, `SEEDANCE_API_KEY`, `GEMINI_API_KEY`) Railway дээр байхгүй. Hidden загвар хэрэглэгчид огт харагдахгүй. |
| Загварыг устгаж болохгүй | Үүсгэлт хийгдсэн тул. Hide дар. |
